Welcome to the Doors! A demo horror game where you! (The player) get traverse through different levels of the backrooms! It was alot of fun trying to make this project and I am over all very happy with how it came out! I had lots of nightmares when adding the jumpscare system because it was so random and quick, haha ill make sure to tone it down a notch next time! This project took over 13 hours and I am really pleased with how it turned out, from the level design to the dialogue and everything, I learned a lot from creating this and this will in fact help me on my next project!

HOW TO PLAY!!
Download the EXE from releases and simply run it to play!
OR you can download from the source and open the EXE in the "dist" folder!

This project was made for TERRA ysws Hackclub

BE CAREFUL!!!
THERE ARE RANDOM JUMPSCARES AND LOUD MUSIC!! (I suggest you obviously turn down your volume before playing)
